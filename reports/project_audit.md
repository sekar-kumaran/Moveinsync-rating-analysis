# Project Audit Report

## 1. Existing Architecture
The project currently follows a sequential script-based architecture:
- Data is collected and transformed through a series of scripts: `collect_reviews.py` → `clean_reviews.py` → `classify_reviews.py` → `analyze_reviews.py` → `build_dashboard_data.py` → `train_model.py`.
- Notebooks are not maintained as standard `.ipynb` files. Instead, they are programmatically generated by `notebooks/generate_notebooks.py`.
- The frontend is a monolithic Streamlit application `app/streamlit_app.py` instead of a modern multi-page Streamlit application.

## 2. Current Application Entry Point
- **Dashboard:** `app/streamlit_app.py` (run via `streamlit run`).
- **Data Pipeline:** Executed via `Makefile` or running Python scripts individually from `src/`.

## 3. Current Dataset Location
- **Raw Data:** `data/raw/google_play_reviews.csv` (10,144 reviews collected).
- **Processed Data:** `data/processed/google_play_reviews_clean.csv`, `google_play_reviews_classified.csv`, and JSON summaries.
- **Sample Data:** `data/sample/` (empty or missing).

## 4. Existing Notebook Status
- No `.ipynb` files are currently present in the repository.
- There is a `notebooks/generate_notebooks.py` script that dynamically generates three separate notebooks for cleaning, EDA, and ML. This approach needs to be refactored into a single, primary analysis workspace (`notebooks/01_moveinsync_eda_and_ml.ipynb`) as requested by the requirements.

## 5. Existing ML Models and Artifacts
- The `models/` directory exists but is currently empty.
- `train_model.py` is designed to output `complaint_classifier.pkl` and `model_card.json`, but these artifacts have not been generated or are missing from the current state.

## 6. Broken Imports and Dependencies
- `requirements.txt` contains standard packages (`pandas`, `scikit-learn`, `streamlit`, `plotly`, `nltk`, etc.). No immediate broken imports observed in the code logic, but the environment needs to be validated.

## 7. Duplicate or Obsolete Python Files
- `notebooks/generate_notebooks.py` will become obsolete once the primary `.ipynb` is created.
- The fragmented scripts (`clean_reviews.py`, `classify_reviews.py`, `analyze_reviews.py`, `build_dashboard_data.py`, `train_model.py`) contain logic that should be moved to the primary notebook (for EDA/exploration) and reusable modules in `src/moveinsync/` (for application logic).
- `app/streamlit_app.py` is a monolithic file that should be archived and refactored into a multi-page app in `app/pages/`.

## 8. Features That Already Work
- Raw review data collection pipeline (`collect_reviews.py`).
- Keyword-based text classification logic.
- Basic visual analytics and dashboard data preparation logic.

## 9. Features That Are Incomplete or Missing
- A single, exploratory notebook serving as the main analysis workspace.
- Reusable package architecture (`src/moveinsync/`).
- Multi-page Streamlit application (`pages/`).
- Live ML inference integrated into the dashboard (current logic relies mostly on precomputed JSONs).
- Trained and saved ML models (missing in `models/`).

## 10. Safe Refactoring Plan
1. **Preserve Data:** Keep `data/raw/google_play_reviews.csv` untouched.
2. **Setup Primary Notebook:** Extract the logic from `generate_notebooks.py` and run it to create `01_moveinsync_eda_and_ml.ipynb`. Run the notebook to generate `processed` datasets and `models/` artifacts.
3. **Refactor Core Logic:** Create the `src/moveinsync/` package. Move data loading, preprocessing, inference, and visualization logic into reusable modules (`data_loader.py`, `preprocessing.py`, `inference.py`, `metrics.py`).
4. **Refactor App:** Create the Streamlit multi-page structure (`app/streamlit_app.py` as entry, `app/pages/*.py` for content). Port logic from the old monolithic app to the new structure, utilizing Plotly for charts and `src/moveinsync/inference.py` for live predictions.
5. **Clean Up:** Archive or remove the obsolete `src/*_reviews.py` and `generate_notebooks.py` scripts once their logic is safely captured in the new structure. Ensure `app/streamlit_app.py` is fully replaced without losing functionality.
6. **Test and Verify:** Run the full pipeline and dashboard locally to ensure no loss of existing functionality and proper ML integration.
